- サブカラー: #A95D84
- ダーク寄りの墨色・濃紫背景

## 大字の曲数表記

曲数を大字で表示する箇所では、位取りを次の表記に統一しています。

- 10 → `壱拾`
- 100 → `壱陌`
- 1000 → `壱阡`
- 10000 → `壱萬`
- 13210 → `壱萬参阡弐陌壱拾`

数字は `壱・弐・参・肆・伍・陸・漆・捌・玖` を使用します。


## メンバー限定配信の設定
`data/archives.js` の各アーカイブに `membersOnly` を設定できます。

```js
{
  "date": "2026-12-23",
  "membersOnly": true,
  "title": "配信タイトル",
  ...
}
```

- メンバー限定配信: `membersOnly: true`
- 通常配信: `membersOnly: false`（省略した場合も通常配信として扱います）
- TOP（PC）、歌枠の記録、歌唱履歴、アーカイブ詳細に「メン限」バッジが表示されます
